Night Launcher gets its own data folder.

- **New folder:** data now lives in `%LOCALAPPDATA%\Night Launcher`. New users start there; nothing from Kestrel is needed
- **Your data comes along:** if you used 1.1.0 or earlier, everything in `%LOCALAPPDATA%\Kestrel` is copied on first start, every file is checked against the original, and only then does the launcher switch over. The old folder stays untouched as a backup until you remove it in Settings > Advanced (it goes to the Recycle Bin). If the copy is interrupted, it resumes next time
- **More reliable paths:** the data folder now comes from Windows directly, so it is right however and wherever Night Launcher is started; missing folders are recreated automatically
