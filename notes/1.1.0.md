Instances and an account switcher.

- **Instances:** keep separate Minecraft setups, each with its own mods, resource packs, options and keybinds, worlds, screenshots, logs and Night cosmetics. Create, rename, duplicate, delete (to a recoverable trash), set a default, and run several at once. Your existing game folder is the Default instance, unchanged
- **Per-instance settings:** account, memory, Java, window size and performance preset. The Cosmetics and Mods pages and the game settings show which instance you are editing
- **Account switcher:** save several Microsoft accounts and switch between them from the sidebar, or from the new ACCOUNTS button on the in-game main menu. Switching in game changes the account for the next server you join without restarting Minecraft. Expired sign-ins are marked so you can sign in again
- Each instance can use the active account, a specific saved account, or offline mode
