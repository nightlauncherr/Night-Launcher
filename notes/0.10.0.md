A completely redesigned Kestrel launcher, and Microsoft sign-in that works out of the box.

- **New launcher design:** the same look as Kestrel's in-game menu: graphite backdrop with flowing ribbons, the Kestrel logo, a new font, sharp icons, smooth hover and page animations, and notifications in the corner. The ribbons only move while the launcher is focused and on Home, so it stays idle in the background
- **New Home dashboard:** one big Play button that shows each step (installing, starting, running) with progress and Cancel, your player with the skin the game will use, and tiles for installation, version, updates and account
- **Reorganised sections:** Home, Cosmetics (kill effects, skies, capes and now Skin), Mods (mod manager, resource packs and performance presets), Settings (game, Java & memory, updates, advanced), Account, About, and Logs at the bottom of the sidebar
- **Microsoft sign-in works for everyone:** Kestrel now has its own Microsoft app built in, so Account → Sign in with Microsoft works without any setup
- Fullbright was removed from the launcher (use a Fullbright mod instead); if Kestrel's built-in Fullbright was on, it is switched off once
- Works at any window size and Windows display scaling; the sidebar shrinks to icons on small windows
- Your settings, accounts, game files, mods, resource packs, capes, skies, skins and kill effects are kept
